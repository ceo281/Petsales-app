# Surface: scam checker home (app/page.tsx)

Mode: Persuade (the visitor decides to check an ad and acts on the report).
Audience: Australian buyer about to pay a deposit on a puppy or kitten from Gumtree, usually on a phone.
Proof on hand: the real checks the product runs, the example report (labelled), the PetSales logo animals, the dog photo. No testimonials or statistics exist.
Constraints: brand-pinned palette (#12053B indigo, #17E4D6 aqua, white); no sales push to PetSales listings; warning signs, never accusations.

## Direction contract
THESIS: The page is the checker. The first viewport is a working check beside a report that is already finding warning signs, refusing the category default of a marketing hero that only describes the tool.
OWN-WORLD: PetSales indigo night, aqua used as a highlighter chip on the decisive words, line-drawn animals from the logo used as stickers between sections, uppercase tracked button labels, Rubik for UI, Archivo for display, mono only for scores and numbers. System grammar adapted from the Sentry design system (midnight canvas, keyword chip, sticker rhythm).
STORY: Paste the ad, watch the report find the signs, understand every reason, then follow the five rules before paying.
FIRST VIEWPORT: Left 55%: headline "Check the pet ad" with "before you pay" set in an aqua chip, one sentence, the link field and CHECK LISTING button. Right 45%: the example report with its score ring and warning rows revealing one by one. Primary action inside the left column at thumb height on mobile.
FORM: Sentry-derived midnight console with keyword chip, position 1 of 1 (brief-pinned brand; concept-seed roll not run because the visual world is pinned by the owner). Seed key: none (pinned).
SIGNATURE INTERACTION: the example report scans: warning rows tick in sequentially once, with the score ring settling last; static under reduced motion.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
